Voice Dictation Daemon (vdict)
System-Wide Push-to-Talk Voice Dictation for Windows
Project location: voice-dictation/

==============================================================================
PROJECT PURPOSE
==============================================================================

PRIMARY: VALIDATION TESTBED FOR STT STACK
  Build a simple voice-to-text dictation tool that validates the
  speech-to-text (STT) components. Dogfood your own dependencies before
  deploying to critical systems. If this tool works reliably for daily
  dictation, the same STT stack (Faster-Whisper + audio capture) is proven.

SECONDARY: PRODUCTIVITY TOOL
  System-wide voice dictation daemon with middle mouse button as push-to-talk
  trigger. Transcribed text injected into active application via keyboard
  emulation. Use case: dictate emails, code comments, documentation without
  touching keyboard.

==============================================================================
ARCHITECTURE OVERVIEW
==============================================================================

PROCESS FLOW

  Middle Mouse Button Press (PTT)
      |
  pynput MouseListener (background thread)
      |
  PTTListener detects button_down -> button_up
      |
  AudioCapture records audio buffers during PTT hold
      |
  PTT released -> Audio sent to event queue
      |
  Main Event Loop:
    audio_bytes -> faster_whisper.transcribe()
    text -> KeyboardInjector.type_text()
      |
  Transcribed text appears in active application

THREADING MODEL

  Main Thread:        Event loop (blocks on queue.get())
  Background Thread 1: pynput MouseListener (listens for middle button)
  Background Thread 2: audio.InputStream callback (captures audio chunks)
  Synchronization:    queue.Queue (thread-safe) for event passing

==============================================================================
MODULE STRUCTURE
==============================================================================

vdict/audio.py -- Audio capture and management
  AudioCapture: Start/stop recording, return audio bytes
  AudioConfig: Sample rate, channels, chunk size
  Dependencies: sounddevice (PortAudio wrapper), numpy

  API:
    capture = AudioCapture()
    capture.start_recording()
    audio_bytes = capture.stop_recording()

  Error handling:
    No microphone detected -> log error, disable recording
    Audio buffer overflow -> warn user (speech too long)

vdict/stt.py -- Speech-to-text transcription
  STTEngine: Wrapper for faster-whisper model
  TranscriptionResult: Text + confidence score
  Dependencies: faster-whisper

  API:
    engine = STTEngine(model="base.en", device="cuda")
    result = engine.transcribe(audio_bytes)

  Model selection:
    tiny.en:  39MB, fastest, lowest accuracy
    base.en:  74MB, good balance (RECOMMENDED)
    small.en: 244MB, high accuracy, slower

  GPU acceleration: uses CUDA if available, falls back to CPU.

vdict/keyboard.py -- Keyboard injection and PTT detection
  KeyboardInjector: Types text into active application
  PTTListener: Detects middle mouse button press/release
  Dependencies: pynput

  API:
    injector = KeyboardInjector()
    injector.type_text("Hello world")

    listener = PTTListener(on_ptt_start, on_ptt_end)
    listener.start()  # Background thread

  Special handling:
    Respect active input focus
    Handle special characters (newlines, punctuation)
    No injection into password fields

vdict.py -- Main entry point
  1. Load config
  2. Initialize STTEngine
  3. Initialize AudioCapture
  4. Initialize KeyboardInjector
  5. Start PTTListener (background thread)
  6. Event loop:
       while running:
         event = event_queue.get()
         if event.type == "audio":
           text = stt_engine.transcribe(event.audio)
           keyboard_injector.type_text(text)
         elif event.type == "shutdown":
           break

  Signal handling:
    SIGINT (Ctrl+C) -> graceful shutdown
    SIGTERM -> flush buffers, stop threads

==============================================================================
EVENT QUEUE PROTOCOL
==============================================================================

Event types:
  AudioEvent:    { type: "audio",    audio_bytes: bytes, timestamp: float }
  ShutdownEvent: { type: "shutdown" }
  ErrorEvent:    { type: "error",    message: str, exception: Exception }

Queue flow:
  PTTListener -> queue.put(AudioEvent) -> Main Loop -> transcribe() -> type_text()
  Ctrl+C -> signal handler -> queue.put(ShutdownEvent) -> Main Loop exits

==============================================================================
CONFIGURATION (config.json)
==============================================================================

{
  "stt":      { "model": "base.en", "device": "cuda", "language": "en" },
  "audio":    { "sample_rate": 16000, "channels": 1, "device_id": null },
  "ptt":      { "button": "middle", "min_duration_ms": 200 },
  "keyboard": { "inject_newline_on_period": false, "auto_capitalize": true }
}

Key settings:
  device:           "cuda" (GPU) or "cpu" (fallback)
  min_duration_ms:  Ignore clicks shorter than this (prevent accidental activation)
  auto_capitalize:  Capitalize first word of sentences

==============================================================================
TESTING
==============================================================================

TEST 1: Audio Capture
  Run test_audio.py. Press middle mouse, speak "testing one two three", release.
  Pass: audio captured, buffer size matches 16kHz * duration, no overruns.

TEST 2: STT Accuracy
  Run test_stt.py with WAV file. Compare to ground truth.
  Pass: WER < 5% on clear audio. Technical terms transcribed correctly.

TEST 3: PTT Button Detection
  Run test_ptt.py. Short click + 2-second hold.
  Pass: on_ptt_start fires on press, on_ptt_end fires on release, duration +-50ms.

TEST 4: Keyboard Injection
  Open text editor. Run daemon. PTT + "Hello world".
  Pass: text appears at cursor, special characters handled, capitalization correct.

TEST 5: End-to-End
  Daemon running. Focus text input. PTT + speak technical phrase.
  Pass: latency < 2s (PTT release -> injection), transcription accurate.

TEST 6: Error Handling
  Unplug mic, speak gibberish, hold PTT 60s, SIGTERM.
  Pass: no crashes, user-friendly error messages, clean shutdown.

==============================================================================
DEPLOYMENT
==============================================================================

STARTUP ON BOOT (WINDOWS)
  Run install_startup.ps1 to create shortcut in Windows Startup folder.
  Uses pythonw.exe (no console window).
  Verify: reboot, press middle mouse -> transcription works.

SYSTEM TRAY (vdict_tray.py) -- optional
  Green icon: listening. Red icon: recording.
  Right-click: pause/resume, quit, settings.
  Not required for core functionality (daemon works headless).
  Dependencies: pystray, PIL.

==============================================================================
TROUBLESHOOTING
==============================================================================

No audio captured (PTT works, transcription empty):
  Wrong audio device, mic muted, or device unplugged.
  Fix: python -c "import sounddevice as sd; print(sd.query_devices())"
  Set device_id in config.json.
