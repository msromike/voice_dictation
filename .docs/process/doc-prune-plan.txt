DESIGN -- DECISION
==============================================================================
RULE-BY-RULE, NOT FILE-BY-FILE
  One criterion held at a time produces consistent judgment, and every
  instance of one problem is visible together.
  Abandonment boundary is the pass, not the file. The tree is coherent at
  the end of each pass, never mid-pass.

PASS ORDER
  0  doc vs code      a line copying a code fact is deleted. one pointing at
                      a symbol stays. read scope: grep the named symbol, read
                      that function. never the tree. hand-rolled code visited
                      on the way gets its three-word category written to
                      TOOLKIT GAPS. emit only, never act.
  1  doc vs doc       one fact, one location. runs after 0 so code-owned
                      claims are already gone. memory's first move is
                      deleting what the repo now records. method: read one
                      file, then grep the tree for its claims.
  2  dead references  pointers to files with a deletion date, line numbers,
                      bare tags.
  3  history          changelogs, attribution, dates that decorate. a version
                      or hardware that bounds a measurement stays -- removing
                      it turns a scoped fact into a false general one.
  4  decisions        keep the checkable basis, cut the argument. Mike rules
                      the boundary; evidence and rationale read identically.
  5  shape            every remaining line picks a House Style shape or gets
                      OPEN. form only. includes rewriting unstarted build
                      sheet steps as end states.
  6  memory hooks     read every hook without its file. rewrite until it
                      stands alone, because the hook is what operates.

PASSES 0-3 BRING CANDIDATES, MIKE SORTS
  Largely mechanical. The output is a list of lines with their file, not
  paragraphs. Passes 4 and 5 need his judgment per line.

REVISE CHECKS ONE PREDICTION
  Whether DECISION kept its evidence clause. It was named the most likely
  shape to drift, before any of this ran.

YARDSTICK AND GATES GO LAST
  House Style lives in CLAUDE.md and the skills encode the protocols running
  this work. Pruning either mid-pass changes the measure while measuring.

DRIVE-BY REDUNDANCY GETS NO MARKER
  Found outside this work, a redundant line is true today and steers nothing
  wrong until the code moves. Marking costs an edit to a line nobody asked
  for. The true-up sweep owns it.
  Overturned if PASS 0 finds these are common rather than rare.

CONFLICT IS APPLIED IN WHATEVER PASS SURFACES IT
  A contradiction is noticed while reading, not while applying one rule.
  Inside this work it is resolved, not marked. Nothing forbids acting here.
