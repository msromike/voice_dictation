VOICE DICTATION - BUILD SHEET: INFERENCE TUNING

ON THE FLY
  WHY THIS SHAPE
  The app ships float32 on CPU -- the slowest option available -- and one
  compute type per device that nobody chose deliberately. Measurement decides
  the order, then the code probes the hardware and takes the best it supports.
  No plan owns this; it is tuning, not architecture.

Done = the app selects its compute type by probing the device and its thread
count by counting performance cores, and the ordered preference lists behind
both are in spike-notes.txt with the measurements that produced them.

==============================================================================
GOVERNING RULE
==============================================================================
Nothing hardware-dependent ships as a constant. Every such value is probed at
runtime and matched against an ordered preference list. A number measured on
one machine describes that machine and no other.

==============================================================================
STEP 4  TURING ARM  -- DEFERRED. Not required to finish this sheet.
==============================================================================
DECIDED, not skipped. Pre-Ampere ships float16, unmeasured, as a stated
default rather than a measured one. Reasons: the shipped code probes and
walks a preference list, so a card without bfloat16 falls through on its own
and never breaks; float16 is what Turing has tensor cores for and is almost
certainly its right answer anyway; and the users who actually need tuning are
on integrated graphics, which is ARM 2, not on an RTX 2070.

The VRAM question moved to 3d and 3e. It was the part of this arm that was
about correctness rather than speed -- whether large-v3 fits an 8GB card --
and the Ampere run answers it, since the model and precision are the same.

Run it if a pre-Ampere user reports the GPU path being slow. That is the
signal, and nothing else is.

  [ ] 4a  2070 laptop, if ever run: float32, float16, int8_float16 only.
          bfloat16 does not exist pre-Ampere.
