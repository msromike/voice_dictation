==============================================================================
GOVERNING RULE
==============================================================================
A writer that calls save_settings owns some fields and not others.
save_settings serializes the whole model, so every field the writer does
not stamp is written from whatever its snapshot held. Any writer holding a
Config older than the moment of the write re-reads first.
