==============================================================================
GOVERNING RULE -- RULE
==============================================================================
A line either finds a slot in its template or it is deleted. Nothing is
reshaped in place. "Delete before reshape" described a per-line rewrite this
work does not do, and the ordering it forced is what put the deliverable last
and made it look small.

Defer a fix only when a later step would delete the line it touches. A fix
already found and already known gets made where it is found -- carrying it
forward creates a second thing to maintain, which is the problem this sheet
exists to remove.


==============================================================================
TWO RADII -- RULE
==============================================================================
Every pass runs its own criterion twice: within one document first, then
across the tree. Within first, because a document that contradicts itself
produces garbage the moment it is compared against another.

Inside a document the criterion reads against that document's own conclusions.
An open item in JUDGMENT, ASSUMED, BLOCKED, SCRATCHPAD or UNVERIFIED that
DELIVERABLES or a SETTLED block already answers is a hit, not an open item.

STEPS 6, 7 and 8 are single-document by construction. The rule adds nothing
there and is not restated in them.


==============================================================================
FOUR TREES -- FACT
==============================================================================
Every pass runs across all four before it ends.

  .docs/            plans, sheets, backlog, defects, roadmap, spike-notes
  CLAUDE.md         repo root
  .claude/skills/   every skill
  memory            ~/.claude/projects/<repo>/memory, outside git

Out of scope, with reason: code comments (CLAUDE.md's Comments rule governs
them and the commit protocol already reports on them), README and CHANGELOG
(user-facing prose, different audience, README accuracy is backlog's B5).
